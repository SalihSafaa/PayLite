# Team requests

Async questions and asks between the two owners, so nothing gets lost in chat.

## Rules

- **Read this folder before starting any work**, on `main` and on any open branch.
- **After finishing a piece of work, write here** if it needs something from the other owner
  (a review, a decision, a contract change, information).
- **One file per request**, named `YYYY-MM-DD-<from>-to-<to>-<short-topic>.md`
  (`A` = Salih, Wallet API · `B` = Aboalhassan, Activity Service). One file per request means
  two people never edit the same file at once.
- Every file starts with a status line: `Status: Open`, `Status: Answered` or `Status: Done`.
- **To answer:** add a `## Answer` section at the bottom of the same file and set the status.
  Don't delete requests; `Done` ones stay as a record.
- Anything that changes a contract or an ADR still goes through a normal PR with both approvals.
  This folder is for asking, not for deciding in private.
